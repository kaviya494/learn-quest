1. Project Abstract & Pedagogical Rationale

Traditional studying often suffers from the Illusion of Explanatory Depth—students believe they understand an abstract subject after merely reading or watching a lecture, only to falter when required to apply it. The AI Peer Teaching Kit addresses this by implementing the Feynman Technique in a gamified, multi-agent peer environment:

  • Step 1 (Peer Explanation): A friendly Robot peer introduces concepts through simple analogies and structured mental models.
  • Step 2 (Teach-Back Evaluation): The student assumes the teacher's role by explaining the concept to the Doll character, who acts as an inquisitive novice.
  • Step 3 (Immediate Corrective Feedback): Intelligent rubrics evaluate the explanation, highlighting what was understood and what key points were omitted.
  • Step 4 (Gamified Retrieval & Spaced Repetition): 3D Quiz Battles, Boss Trials, Flashcards, and Leitner intervals permanently consolidate memory.

2. Technical Architecture & Design Choices

Built strictly with Plain HTML5, CSS3, and modern Vanilla JavaScript with local Three.js:

  • Zero Build Tools / Zero NPM: Runs directly by double-clicking index.html on any browser.
  • Zero External Asset Dependency: 3D models and procedural sound effects use local Three.js and the native Web Audio API, guaranteeing zero CORS errors on file:///.
  • Dual-Mode AI Engine: Seamlessly operates offline with built-in rubrics and heuristics, with optional live Google Gemini API integration for dynamic grading and custom topic synthesis.
  • Client-Side State Persistence: Profiles, streaks, XP, custom topics, and Leitner schedules are stored reliably in localStorage.

3. Viva Q&A Cheat Sheet (For College Examiners)

Q1: Why use peer teaching rather than standard AI question answering?

A: Standard Q&A keeps the student in a passive reception mode. Peer teaching forces active cognitive reconstruction: the student must translate abstract technical jargon into lucid plain English, exposing misconceptions and strengthening neural connections through generative learning.

Q2: How does the application work without a backend or server?

A: All state management is handled through the browser's persistent localStorage API. Audio is synthesized on the fly via the Web Audio API (Oscillators and Gain nodes), 3D graphics are rendered through WebGL using Three.js, and offline evaluation uses weighted regex rubrics with fallback AI endpoints.

Q3: How are the 3D models of the Robot and Doll created?

A: They are procedurally built using Three.js primitive geometries (Cylinders, Boxes, Spheres, Tori) grouped into hierarchical scene graphs. This avoids heavy external .gltf/.obj files that trigger CORS security errors when loaded directly from local disks (file:///).

Q4: How does the Spaced Repetition Planner function?

A: It implements the Leitner interval model (Days 1, 3, 7, and 14). When a student completes a teach-back session, target review dates are calculated from Date.now(). The interface highlights overdue, due today, and completed reviews.
